Elasticsearch 基础入门

Elasticsearch 是开源的分布式搜索与分析引擎，能对海量文本做毫秒级搜索，底层靠 Lucene 实现，对外暴露 JSON 风格的 REST 接口

📅 2026-08-13⏱ 3 分钟阅读🗄️ 数据库与中间件

Elasticsearch 是开源的分布式搜索与分析引擎，能对海量文本做毫秒级搜索，底层靠 Lucene 实现，对外暴露 JSON 风格的 REST 接口。

核心概念

和关系型数据库做类比：

Elasticsearch 关系型数据库
Index（索引） Database（库）
Type（已废弃） Table（表）
Document（文档) Row（行）
Field（字段） Column（列）

安装与启动

推荐用 Docker 快速起一个单节点：

docker run -d --name es \
  -p 9200:9200 -e "discovery.type=single-node" \
  -e "xpack.security.enabled=false" \
  docker.elastic.co/elasticsearch/elasticsearch:8.12.0

验证：

curl http://localhost:9200

倒排索引

ES 为什么快？因为它不按文档扫描，而是把文本切词后建立单词 → 文档列表的映射：

"Elasticsearch 是搜索引擎"
=>
  elasticsearch -> doc1
  是            -> doc1
  搜索引擎      -> doc1

查询 “搜索引擎” 时直接定位到包含该词的文档，无需全文遍历。分词由分析器（Analyzer）完成，中文常用 ik 或 smartcn 分词器。

创建索引

curl -X PUT localhost:9200/article -H 'Content-Type: application/json' -d '{
  "settings": { "number_of_shards": 1, "number_of_replicas": 0 },
  "mappings": {
    "properties": {
      "title":  { "type": "text", "analyzer": "ik_max_word" },
      "price":  { "type": "integer" },
      "tags":   { "type": "keyword" }
    }
  }
}'

注意：text 类型会被分词用于全文搜索，keyword 类型整体匹配用于精确过滤和聚合。

写入与查询

写入文档：

curl -X POST localhost:9200/article/_doc -H 'Content-Type: application/json' -d '{
  "title": "Python 异步编程实践",
  "price": 10,
  "tags": ["Python", "异步"]
}'

全文搜索：

curl -X POST localhost:9200/article/_search -H 'Content-Type: application/json' -d '{
  "query": { "match": { "title": "异步编程" } }
}'

结构化过滤：

curl -X POST localhost:9200/article/_search -H 'Content-Type: application/json' -d '{
  "query": { "bool": {
    "must":   [ { "term": { "tags": "Python" } } ],
    "filter": [ { "range": { "price": { "lte": 20 } } } ]
  } }
}'

聚合分析

按标签统计热门分类：

curl -X POST localhost:9200/article/_search -H 'Content-Type: application/json' -d '{
  "size": 0,
  "aggs": {
    "hot_tags": { "terms": { "field": "tags.keyword" } }
  }
}'

size: 0 表示不返回文档，只返回聚合结果。

Python 客户端

from elasticsearch import Elasticsearch

es = Elasticsearch("http://localhost:9200")
resp = es.search(index="article", query={"match": {"title": "异步"}})
for hit in resp["hits"]["hits"]:
    print(hit["_source"])

与 MySQL 的关系

ES 凭借灵活性替代 MySQL 做模糊搜索，但做不了事务和复杂关联。常见架构：MySQL 作为主存储，通过 CDC（如 Canal / Logstash）把数据同步到 ES 提供搜索，保证两边一致。

总结

  • Index/Type/Document 对应库/表/行
  • 倒排索引 + 分词是全文检索快的根本
  • text 分词用于 match 搜索，keyword 用于 term/聚合
  • 聚合查询配合 size: 0 拿统计结果
  • ES 一般与 MySQL 搭配，负责搜索部分
