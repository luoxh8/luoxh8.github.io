Linux 常用命令

后端开发天天和服务器打交道，这些命令用得最多

📅 2026-08-07⏱ 2 分钟阅读⚙️ 后端与DevOps

后端开发天天和服务器打交道，这些命令用得最多。

文件与目录

ls -la                 # 查看目录（含隐藏文件）
cd /opt/demo           # 切换目录
pwd                    # 当前路径
cp -r a b              # 复制目录
mv a b                 # 移动/重命名
rm -rf /tmp/old        # 删除目录（慎用）
find / -name "*.log"   # 按名字查找
du -sh /opt            # 目录占用空间
df -h                  # 磁盘使用情况

查看与搜索文件

cat file.txt           # 查看全文
head -n 20 file.txt    # 看开头
tail -n 50 file.txt    # 看结尾
tail -f app.log        # 实时跟踪日志（最常用）
grep -r "ERROR" /opt/app/logs/   # 递归搜索
grep -n "exception" app.log | head

进程管理

ps -ef | grep java     # 查看进程
top                    # 实时资源监控
htop                   # 更友好的 top
kill -9 1234           # 强制结束进程
kill -15 1234          # 优雅结束
nohup java -jar app.jar > app.log 2>&1 &

nohup ... & 让程序在后台运行且不随终端退出。

端口排查

netstat -tlnp | grep 8080   # 谁占用了 8080
ss -tlnp | grep 8080        # 新版系统推荐
lsof -i :8080               # 查看端口对应进程
curl -v http://localhost:8080/health

压缩与传输

tar -czf app.tar.gz /opt/app    # 打包压缩
tar -xzf app.tar.gz             # 解压
zip -r app.zip /opt/app
scp app.jar root@server:/opt/   # 复制到远程
rsync -av /local/ root@server:/remote/

系统资源

free -h                  # 内存
df -h                    # 磁盘
vmstat 2                 # 系统负载
iostat                   # IO 状态
uptime                   # 负载均值
dmesg | tail             # 内核日志（查 OOM）

总结

  • tail -f + grep 排查日志
  • netstat/ss + lsof 排查端口
  • nohup 后台运行，top/free 看资源
