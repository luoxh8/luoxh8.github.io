tmux 让远程终端断开后任务继续跑

📅 2020-08-15⏱ 1 分钟阅读🛠️ 开发工具

tmux 让远程终端断开后任务继续跑。

启动与分离

tmux new -s dev      # 新建会话 dev
tmux detach          # 脱离（快捷键 Ctrl+b d）
tmux ls              # 列出会话
tmux attach -t dev   # 重新接入

窗格与窗口

  • Ctrl+b %：左右分屏
  • Ctrl+b "：上下分屏
  • Ctrl+b 方向键：切换窗格
  • Ctrl+b c：新建窗口
  • Ctrl+b n/p：下一个 / 上一个窗口

常用配置 ~/.tmux.conf

set -g mouse on
set -g base-index 1
bind r source-file ~/.tmux.conf \; display "reloaded"

典型用法

远程跑长任务：

tmux new -s train
# 在里跑 python train.py
# Ctrl+b d 脱离，关掉 SSH 也不中断
# 回来 tmux attach -t train 看进度

注意：窗格内复制需开启鼠标，或进入复制模式（Ctrl+b [）。
