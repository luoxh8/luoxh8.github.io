VS Code 轻量且插件生态强大

VS Code 轻量且插件生态强大。

必装插件

  • Chinese (Simplified) Language Pack：中文界面
  • Python / Java Extension Pack：语言支持
  • Prettier / ESLint：格式化与规范
  • GitLens：增强 Git 注解
  • Docker / Kubernetes：容器集成
  • Error Lens：行内显示错误

提效快捷键

  • Ctrl+Shift+P：命令面板
  • Ctrl+P：快速打开文件
  • Alt+Click：多光标
  • Ctrl+D：选中下一个相同词
  • Ctrl+`` ：集成终端
  • Ctrl+K Ctrl+S：快捷键设置

用户设置片段

{
  "editor.formatOnSave": true,
  "editor.multiCursorModifier": "alt",
  "files.autoSave": "afterDelay",
  "workbench.colorTheme": "Default Dark+"
}

技巧

  • 命令面板输入 >format 选格式化。
  • 选中代码按 Ctrl+K Ctrl+F 格式化选区。
  • Ctrl+Shift+M 打开问题面板集中看错误。
