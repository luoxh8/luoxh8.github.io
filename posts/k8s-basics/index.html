Kubernetes 核心概念

K8s 编排容器，提供自愈、扩缩容与负载均衡

📅 2023-09-12⏱ 1 分钟阅读⚙️ 后端与DevOps

K8s 编排容器，提供自愈、扩缩容与负载均衡。

核心对象

  • Pod：最小调度单位，含一个或多个容器
  • Deployment：管理 Pod 副本与滚动更新
  • Service：稳定访问入口（ClusterIP / NodePort / LoadBalancer）
  • ConfigMap / Secret：配置与密钥

最小部署

apiVersion: apps/v1
kind: Deployment
metadata:
  name: web
spec:
  replicas: 3
  selector:
    matchLabels: { app: web }
  template:
    metadata:
      labels: { app: web }
    spec:
      containers:
        - name: web
          image: nginx:1.27
          ports:
            - containerPort: 80
---
apiVersion: v1
kind: Service
metadata:
  name: web-svc
spec:
  selector: { app: web }
  ports:
    - port: 80
      targetPort: 80
  type: NodePort

常用命令

kubectl apply -f deploy.yaml
kubectl get pods
kubectl scale deployment web --replicas=5
kubectl rollout status deployment web
kubectl rollout undo deployment web   # 回滚

要点

  • 容器退出即重启（自愈）。
  • 无状态服务用 Deployment，有状态用 StatefulSet。
  • 暴露外部用 Service(LoadBalancer) 或 Ingress。
