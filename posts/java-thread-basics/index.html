Java 多线程基础

Java 中创建线程有三种常见方式

📅 2026-08-07⏱ 1 分钟阅读☕ Java

多线程是后端高并发的基石。Java 中创建线程有三种常见方式。

方式一：继承 Thread

class MyThread extends Thread {
    @Override
    public void run() {
        System.out.println(Thread.currentThread().getName());
    }
}

new MyThread().start();

方式二：实现 Runnable（推荐）

Runnable task = () -> System.out.println("run");
new Thread(task).start();

实现接口比继承类更灵活，任务与线程解耦。

方式三：Callable + Future

需要返回值时使用：

ExecutorService pool = Executors.newFixedThreadPool(4);

Future<Integer> future = pool.submit(() -> 1 + 2);
Integer result = future.get();  // 阻塞获取结果

线程生命周期

新建 NEW → 就绪 RUNNABLE → 运行 RUNNING
              ↑              ↓
              ←──── 阻塞 BLOCKED / WAITING / TIMED_WAITING
运行结束 → 终止 TERMINATED

常用方法：

thread.start();      // 启动线程
thread.join();       // 等待线程结束
thread.interrupt();  // 中断线程
Thread.sleep(1000);  // 休眠 1 秒

线程安全与 synchronized

多个线程同时修改共享变量会出问题：

class Counter {
    private int count = 0;

    public synchronized void increment() {
        count++;
    }
}

synchronized 可以修饰方法，也可以修饰代码块（缩小锁粒度）：

public void increment() {
    synchronized (this) {
        count++;
    }
}

volatile 与可见性

volatile 保证变量修改对其他线程可见，但不保证原子性：

volatile boolean running = true;

// 另一个线程修改 running，这里能立即看到
while (running) {
    work();
}

总结

  • 优先用 Runnable/Callable 而不是继承 Thread
  • 共享数据用 synchronized 保护
  • volatile 解决可见性，原子性还是要靠锁或原子类
