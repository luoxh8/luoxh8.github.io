MongoDB 使用入门

MongoDB 是文档型 NoSQL 数据库，JSON 式存储，适合灵活多变的业务模型

📅 2026-08-07⏱ 2 分钟阅读🗄️ 数据库与中间件

MongoDB 是文档型 NoSQL 数据库，JSON 式存储，适合灵活多变的业务模型。

核心概念

MySQL MongoDB
数据库 database 数据库 database
表 table 集合 collection
行 row 文档 document
字段 column 字段 field

基本操作

docker run -d -p 27017:27017 --name mongo mongo:7
// 插入
db.users.insertOne({ name: "luoxh", age: 26, skills: ["Java", "Python"] })

// 查询
db.users.find({ age: { $gte: 20 } })
db.users.find({ "skills": "Java" })
db.users.find().sort({ age: -1 }).limit(10)

// 更新
db.users.updateOne({ name: "luoxh" }, { $set: { age: 27 } })

// 删除
db.users.deleteOne({ name: "luoxh" })

索引

// 单字段索引
db.users.createIndex({ name: 1 })

// 复合索引
db.users.createIndex({ age: 1, name: -1 })

// 唯一索引
db.users.createIndex({ email: 1 }, { unique: true })

// 查看执行计划
db.users.find({ name: "luoxh" }).explain("executionStats")

聚合管道

db.orders.aggregate([
    { $match: { status: "paid" } },
    { $group: { _id: "$userId", total: { $sum: "$amount" } } },
    { $sort: { total: -1 } },
    { $limit: 10 }
])

Java 集成

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-mongodb</artifactId>
</dependency>
@Document(collection = "users")
public class User {
    @Id
    private String id;
    private String name;
    private Integer age;
}

@Repository
public interface UserRepository extends MongoRepository<User, String> {
    List<User> findByAgeGreaterThan(Integer age);
}

场景选择

适合 MongoDB：

  • 字段结构经常变化（配置、埋点、日志）
  • 海量写入、查询简单
  • 需要内嵌数组/对象

不适合：

  • 强事务、复杂多表关联
  • 强一致性的财务类数据

总结

  • 文档模型灵活，随业务扩展字段
  • 记得建索引，否则全集合扫描
  • 与 MySQL 各司其职，别强行二选一
