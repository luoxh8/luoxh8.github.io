Java 集合框架速查

集合分三大类：List（有序可重复）、Set（不可重复）、Map（键值对）

📅 2021-04-16⏱ 1 分钟阅读☕ Java

集合分三大类：List（有序可重复）、Set（不可重复）、Map（键值对）。

List

List<String> list = new ArrayList<>();   // 查改快，增删慢
List<String> link = new LinkedList<>();  // 头尾增删快
List<String> vec = new Vector<>();       // 线程安全但慢

Set

Set<String> hs = new HashSet<>();        // 无序，O(1)
Set<String> ts = new TreeSet<>();        // 有序（红黑树）
Set<String> ls = new LinkedHashSet<>();  // 保插入顺序

Map

Map<String, Integer> m = new HashMap<>();         // 最常用
Map<String, Integer> tm = new TreeMap<>();        // key 有序
Map<String, Integer> sm = new LinkedHashMap<>();  // 保插入序，缓存常用

遍历

for (String s : list) { }
list.forEach(System.out::println);
map.forEach((k, v) -> System.out.println(k + v));

线程安全

List<String> safe = Collections.synchronizedList(new ArrayList<>());

import java.util.concurrent.ConcurrentHashMap;
ConcurrentHashMap<String, Integer> chm = new ConcurrentHashMap<>();

选型

  • 需要去重 → HashSet
  • 需要排序 → TreeSet / TreeMap
  • 缓存 LRU → LinkedHashMap
  • 高并发 → ConcurrentHashMap
