SSH 配置与免密登录

SSH 是连接服务器的基本方式，配好密钥和 config，操作行云流水

📅 2020-01-14⏱ 1 分钟阅读🛠️ 开发工具

SSH 是连接服务器的基本方式，配好密钥和 config，操作行云流水。

生成密钥

ssh-keygen -t ed25519 -C "luoxh@example.com"

一路回车，密钥生成在 ~/.ssh/：

id_ed25519      私钥（别外传）
id_ed25519.pub  公钥（放到服务器）

免密登录

把公钥加到服务器：

ssh-copy-id root@192.168.1.20
# 或手动追加
cat ~/.ssh/id_ed25519.pub | ssh root@192.168.1.20 "cat >> ~/.ssh/authorized_keys"

之后 ssh root@192.168.1.20 直接登录。

配置 config

编辑 ~/.ssh/config，给服务器起别名：

Host prod
    HostName 192.168.1.20
    User root
    Port 22
    IdentityFile ~/.ssh/id_ed25519

Host github
    HostName github.com
    User git
    IdentityFile ~/.ssh/id_ed25519

然后：

ssh prod
git clone github:luoxh8/blog.git

远程执行与传输

# 远程执行命令
ssh prod "systemctl restart nginx"

# 复制文件
scp app.jar prod:/opt/demo/

# 同步目录
rsync -avz ./dist prod:/var/www/blog/

常见问题

Permission denied：检查公钥是否在 authorized_keys、私钥权限：

chmod 600 ~/.ssh/id_ed25519
chmod 700 ~/.ssh

连接卡住：加 -v 看日志：

ssh -v prod

总结

  • ed25519 密钥 + ssh-copy-id 实现免密
  • config 文件管理多个服务器
  • rsync 部署前端、scp 传包
