以下是我日常开发中常用的 IDEA 插件：

  • EditStarters：可视化编辑 Spring Boot Starter 依赖
  • RestfulTool：一键生成与调试 RESTful 接口
  • Maven Helper：依赖冲突分析与快速执行
  • Spring Assistant：Spring 配置智能提示
  • GenerateAllSetter：一键生成所有 setter 调用
  • Translation：翻译插件，注释与报错即时翻译
  • SequenceDiagram：一键生成方法调用时序图
  • Json Helper：JSON 格式化与校验
