Docker 常用命令

重新打包新镜像 启动一个新的容器 启动一个新的容器（测试用） 停止并删除所有容器

📅 2019-02-02🔄 更新于 2019-03-15⏱ 1 分钟阅读⚙️ 后端与DevOps

重新打包新镜像

docker build -t docker001:1.0.2 .

启动一个新的容器

docker run -d \
-p 8123:80 \
-v /root/test:/docker001 \
--name=docker001 \
docker001:1.0.2

启动一个新的容器（测试用）

docker run -it \
-v /root/test:/docker001 \
-p 8333:80 \
docker001:1.0.2 bash

停止并删除所有容器

# 停止所有容器
docker stop $(docker ps -a -q)

# 删除所有容器
docker rm $(docker ps -a -q)

# 删除没有名字的镜像（悬空镜像）
docker rmi $(docker images -f "dangling=true" -q)
