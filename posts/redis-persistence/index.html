Redis 持久化 RDB 与 AOF

Redis 是内存库，持久化保证重启不丢数据

📅 2022-06-24⏱ 1 分钟阅读🗄️ 数据库与中间件

Redis 是内存库，持久化保证重启不丢数据。

RDB（快照）

定时把内存全量写入 .rdb。

save 900 1           # 900s 内至少 1 次修改
save 300 10
save 60 10000
dbfilename dump.rdb
dir /data

优点：文件紧凑、恢复快。缺点：可能丢最后一次快照后的数据。

AOF（追加日志）

记录每条写命令。

appendonly yes
appendfsync everysec   # 折中：每秒刷盘
# always  每次写都刷，最安全最慢
# no      由系统决定

AOF 文件会膨胀，bgrewriteaof 重写压缩。

混合持久化

Redis 4.0+ 推荐：

aof-use-rdb-preamble yes

AOF 文件头部嵌入 RDB，兼顾恢复速度与安全。

选型

  • 允许少量丢失、追求恢复速度 → RDB
  • 追求不丢 → AOF（everysec）
  • 生产默认 → 混合持久化
