Python 上下文管理器（with 语句）

📅 2019-05-18⏱ 1 分钟阅读🐍 Python

上下文管理器用于自动管理资源，最常见的就是 with open(...) 自动关闭文件。理解它的原理，可以让自己的类也支持 with 语句。

基础用法

with open('a.txt', 'w') as f:
    f.write('hello')
# 离开 with 块自动关闭文件，即使发生异常也会关闭

实现原理

with 语句会调用对象的两个魔术方法：

  • __enter__：进入时执行，返回值绑定给 as 后面的变量
  • __exit__：离开时执行（无论是否异常），负责清理资源
class MyFile:
    def __init__(self, name):
        self.name = name

    def __enter__(self):
        print('open', self.name)
        return self

    def __exit__(self, exc_type, exc_val, exc_tb):
        print('close', self.name)
        # 返回 True 表示吞掉异常
        return False

with MyFile('a.txt') as f:
    print('working')

输出：

open a.txt
working
close a.txt

__exit__ 的三个参数分别对应异常类型、异常对象、堆栈信息。没有异常时它们都是 None。

使用 contextlib

标准库 contextlib 提供了更简洁的写法：

from contextlib import contextmanager

@contextmanager
def my_file(name):
    print('open', name)
    try:
        yield name
    finally:
        print('close', name)

with my_file('a.txt') as f:
    print('working with', f)

yield 之前的代码相当于 __enter__，yield 之后（或 finally 中）的代码相当于 __exit__。

实战：统计耗时

import time
from contextlib import contextmanager

@contextmanager
def timer(label):
    start = time.time()
    yield
    print(f'{label} 耗时: {time.time() - start:.3f}s')

with timer('查询'):
    time.sleep(0.2)

总结

  • __enter__ / __exit__ 是上下文管理器的核心
  • contextlib.contextmanager 用生成器语法快速实现
  • 数据库连接、文件、锁等资源都适合用 with 管理
