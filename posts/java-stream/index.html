Java Stream API 与 Lambda

Stream 让集合操作声明式、可链式

📅 2021-05-21⏱ 1 分钟阅读☕ Java

Stream 让集合操作声明式、可链式。

基础

List<Integer> nums = List.of(1, 2, 3, 4, 5);
List<Integer> even = nums.stream()
    .filter(n -> n % 2 == 0)
    .map(n -> n * n)
    .toList();              // [4, 16]

常用终端操作

long count = nums.stream().filter(n -> n > 2).count();
int sum = nums.stream().mapToInt(Integer::intValue).sum();
Optional<Integer> max = nums.stream().max(Integer::compareTo);
boolean any = nums.stream().anyMatch(n -> n > 4);

reduce 聚合

int total = nums.stream().reduce(0, Integer::sum);
String joined = nums.stream()
    .map(String::valueOf)
    .collect(Collectors.joining(","));

分组

Map<Boolean, List<Integer>> g = nums.stream()
    .collect(Collectors.partitioningBy(n -> n % 2 == 0));
Map<Integer, Long> freq = nums.stream()
    .collect(Collectors.groupingBy(n -> n, Collectors.counting()));

并行流

nums.parallelStream().forEach(System.out::println);   // 大数据量才划算

注意：并行流有线程开销，且要避免共享可变状态。
