Python 类型注解与 typing

类型注解不影响运行，但能提升可读性与静态检查能力

📅 2022-04-15⏱ 1 分钟阅读🐍 Python

类型注解不影响运行，但能提升可读性与静态检查能力。

变量与函数

name: str = "luoxh"

def add(a: int, b: int) -> int:
    return a + b

容器与可选

from typing import List, Dict, Optional, Union, Tuple

scores: List[int] = [90, 85]
info: Dict[str, str] = {"k": "v"}
maybe: Optional[int] = None            # 等价 int | None (3.10+)
pair: Tuple[int, str] = (1, "a")

别名与新语法

from typing import TypeAlias

Vector: TypeAlias = List[float]

def f(x: int | str) -> bool:           # 3.10+ 联合类型
    ...

泛型

from typing import TypeVar, Generic

T = TypeVar("T")

class Box(Generic[T]):
    def __init__(self, v: T):
        self.v = v
