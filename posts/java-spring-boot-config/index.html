Spring Boot 配置管理

配置管理是项目工程化的基础

📅 2023-03-09⏱ 1 分钟阅读☕ Java

配置管理是项目工程化的基础。Spring Boot 支持 application.properties 和 application.yml，推荐使用 yml。

基础配置

server:
  port: 8080

spring:
  application:
    name: demo-service
  datasource:
    url: jdbc:mysql://localhost:3306/demo?useSSL=false
    username: root
    password: 123456

多环境配置

通过 spring.profiles.active 切换环境：

# application.yml
spring:
  profiles:
    active: dev
# application-dev.yml
server:
  port: 8080

# application-prod.yml
server:
  port: 8081

启动时指定：

java -jar app.jar --spring.profiles.active=prod

类型安全的配置绑定

使用 @ConfigurationProperties 把配置绑定到类，比到处写 @Value 更清晰：

app:
  upload:
    path: /data/upload
    max-size: 10MB
@ConfigurationProperties(prefix = "app.upload")
@Component
public class UploadConfig {
    private String path;
    private String maxSize;

    // getter / setter
}

常用配置项

server:
  port: 8080
  servlet:
    context-path: /api

spring:
  mvc:
    format:
      date-time: yyyy-MM-dd HH:mm:ss
  servlet:
    multipart:
      max-file-size: 20MB
      max-request-size: 50MB
  jackson:
    time-zone: Asia/Shanghai

logging:
  level:
    root: info
    com.example.mapper: debug

配置的优先级

Spring Boot 配置遵循固定顺序，后者覆盖前者：

  1. 命令行参数（最高）
  2. SPRING_APPLICATION_JSON 环境变量
  3. application-{profile}.yml
  4. application.yml
  5. 默认配置
java -jar app.jar --server.port=9090

总结

  • 用 spring.profiles.active 区分 dev/prod 环境
  • 复杂配置用 @ConfigurationProperties 绑定
  • 命令行参数优先级最高，适合部署时临时覆盖
