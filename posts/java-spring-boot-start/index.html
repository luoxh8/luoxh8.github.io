Spring Boot 快速入门

Spring Boot 让 Java 后端开发变得简单：内嵌 Tomcat、自动配置、起步依赖，开箱即用

📅 2024-03-15⏱ 1 分钟阅读☕ Java

Spring Boot 让 Java 后端开发变得简单：内嵌 Tomcat、自动配置、起步依赖，开箱即用。

创建项目

推荐使用 Spring Initializr 生成项目，选择 Java 17 + Spring Boot 3.x，勾选 Web 依赖。

也可以用 Maven 直接建：

<parent>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-parent</artifactId>
    <version>3.3.5</version>
</parent>

<dependencies>
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-web</artifactId>
    </dependency>
</dependencies>

启动类

@SpringBootApplication
public class DemoApplication {
    public static void main(String[] args) {
        SpringApplication.run(DemoApplication.class, args);
    }
}

@SpringBootApplication 组合了 @Configuration、@EnableAutoConfiguration 和 @ComponentScan。

第一个接口

@RestController
@RequestMapping("/api/users")
public class UserController {

    @GetMapping("/hello")
    public String hello(@RequestParam String name) {
        return "Hello, " + name;
    }

    @PostMapping
    public User create(@RequestBody User user) {
        return user;
    }
}

启动后访问 http://localhost:8080/api/users/hello?name=luoxh。

依赖注入

@Service
public class UserService {
    public String greet() {
        return "hi";
    }
}

@RestController
public class UserController {
    private final UserService userService;

    // 构造器注入，推荐方式
    public UserController(UserService userService) {
        this.userService = userService;
    }
}

常用注解速查

注解 作用
@RestController REST 控制器，返回 JSON
@Service / @Repository 业务层 / 数据层组件
@Autowired 自动注入
@Configuration 配置类
@Value 读取配置项
@Transactional 开启事务

总结

  • Spring Boot 通过自动配置和起步依赖简化开发
  • 组件用注解注册，通过依赖注入协作
  • 内嵌 Tomcat，打包成 jar 直接运行
