Maven 依赖管理与构建

Maven 是 Java 项目的事实标准构建工具，统一管理依赖、打包、发布

📅 2023-06-08⏱ 1 分钟阅读☕ Java

Maven 是 Java 项目的事实标准构建工具，统一管理依赖、打包、发布。

核心概念

  • 坐标：groupId:artifactId:version 唯一定位一个构件
  • 仓库：本地仓库 → 私服/中央仓库
  • 生命周期：validate → compile → test → package → install → deploy

pom.xml 示例

<project>
    <modelVersion>4.0.0</modelVersion>
    <groupId>com.example</groupId>
    <artifactId>demo</artifactId>
    <version>1.0.0</version>
    <packaging>jar</packaging>

    <dependencies>
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-web</artifactId>
            <version>3.3.5</version>
        </dependency>
    </dependencies>
</project>

常用命令

mvn clean                 # 清理 target
mvn compile               # 编译
mvn test                  # 跑测试
mvn package               # 打包
mvn install               # 安装到本地仓库
mvn dependency:tree       # 查看依赖树
mvn dependency:analyze    # 检查未使用的依赖

跳过测试打包：

mvn package -DskipTests

依赖冲突

依赖传递会引入版本冲突，用依赖树定位：

mvn dependency:tree -Dincludes=com.google.guava:guava

排除传递依赖：

<dependency>
    <groupId>com.example</groupId>
    <artifactId>lib</artifactId>
    <version>1.0</version>
    <exclusions>
        <exclusion>
            <groupId>commons-logging</groupId>
            <artifactId>commons-logging</artifactId>
        </exclusion>
    </exclusions>
</dependency>

或者统一指定版本（推荐）：

<dependencyManagement>
    <dependencies>
        <dependency>
            <groupId>com.google.guava</groupId>
            <artifactId>guava</artifactId>
            <version>33.2.0-jre</version>
        </dependency>
    </dependencies>
</dependencyManagement>

配置镜像与私服

修改 ~/.m2/settings.xml，国内常用阿里云镜像：

<mirrors>
    <mirror>
        <id>aliyun</id>
        <mirrorOf>central</mirrorOf>
        <url>https://maven.aliyun.com/repository/public</url>
    </mirror>
</mirrors>

总结

  • 用坐标管理依赖，dependency:tree 排查冲突
  • 多模块项目用 dependencyManagement 统一版本
  • 内网环境配私服或镜像加速
