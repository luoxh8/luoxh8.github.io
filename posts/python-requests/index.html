Python requests 网络请求实战

requests 是 Python 最流行的 HTTP 客户端库，写接口调用、爬虫、脚本都离不开它

📅 2022-03-22⏱ 1 分钟阅读🐍 Python

requests 是 Python 最流行的 HTTP 客户端库，写接口调用、爬虫、脚本都离不开它。

安装与基础请求

pip install requests
import requests

# GET 请求
r = requests.get('https://api.example.com/users', params={'page': 1})
print(r.status_code)   # 200
print(r.json())        # 解析 JSON

# POST 请求
r = requests.post(
    'https://api.example.com/login',
    json={'username': 'luoxh', 'password': '***'},
)

params 会自动拼接到 URL，json= 会自动设置 Content-Type: application/json。

请求头与超时

headers = {
    'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64)',
    'Authorization': 'Bearer xxxxx',
}

r = requests.get(url, headers=headers, timeout=10)

超时必须设置，否则遇到慢接口会一直挂起。推荐 (connect, read) 元组：

r = requests.get(url, timeout=(5, 10))

处理异常与重试

from requests.adapters import HTTPAdapter
from urllib3.util.retry import Retry

session = requests.Session()
retry = Retry(total=3, backoff_factor=1, status_forcelist=[500, 502, 503])
session.mount('https://', HTTPAdapter(max_retries=retry))

try:
    r = session.get(url, timeout=10)
    r.raise_for_status()
except requests.RequestException as e:
    print('请求失败', e)

Session 保持会话

登录后需要携带 Cookie 的场景，用 Session 保持状态：

session = requests.Session()
session.post('https://api.example.com/login', json=payload)

# 后续请求自动携带 Cookie
data = session.get('https://api.example.com/me').json()

文件上传与下载

# 上传
files = {'file': open('a.png', 'rb')}
requests.post('https://api.example.com/upload', files=files)

# 流式下载大文件
with requests.get(download_url, stream=True) as r:
    with open('big.zip', 'wb') as f:
        for chunk in r.iter_content(chunk_size=8192):
            f.write(chunk)

代理与关闭证书校验

proxies = {'http': 'http://127.0.0.1:7890', 'https': 'http://127.0.0.1:7890'}
r = requests.get(url, proxies=proxies, verify=False)

verify=False 仅限测试环境，生产环境请使用正式证书。

总结

  • 用 params/json/headers 组织请求，代码更清晰
  • 永远设置 timeout
  • 用 Session + Retry 处理登录态与临时故障
