Lombok 简化 Java 开发

Lombok 通过注解在编译期自动生成 getter/setter、构造器、日志对象等样板代码

📅 2022-05-06⏱ 1 分钟阅读☕ Java

Lombok 通过注解在编译期自动生成 getter/setter、构造器、日志对象等样板代码。

引入依赖

<dependency>
    <groupId>org.projectlombok</groupId>
    <artifactId>lombok</artifactId>
    <optional>true</optional>
</dependency>

IDEA 需要安装 Lombok 插件，并开启 Annotation Processing。

常用注解

@Data                    // 生成 getter/setter/toString/equals/hashCode
@Builder                 // 建造者模式
@NoArgsConstructor       // 无参构造器
@AllArgsConstructor      // 全参构造器
public class User {
    private Long id;
    private String name;
}

// 使用
User user = User.builder()
        .id(1L)
        .name("luoxh")
        .build();

日志注解

@Slf4j
@Service
public class UserService {
    public void doWork() {
        log.info("开始处理, id={}", 100);
        log.error("出错了", new RuntimeException("x"));
    }
}

自动生成 log 对象，等价于手写：

private static final Logger log = LoggerFactory.getLogger(UserService.class);

实体类完整示例

@Data
@Builder
@NoArgsConstructor
@AllArgsConstructor
public class Order {
    private Long id;
    private String orderNo;
    private BigDecimal amount;
    private LocalDateTime createdAt;
}

注意事项

  • @Data 不适合 JPA 实体（toString 可能循环引用），可改用 @Getter @Setter
  • 继承场景注意 @SuperBuilder
  • 与 MapStruct 等编译期工具配合时，注解处理器顺序要对
  • 传递 DTO 之间复制可以用 @Mapping 或手写，别滥用 @Data

总结

  • 用 @Data/@Builder/@Slf4j 大幅减少样板代码
  • 团队统一约定，避免 Lombok 滥用
  • IDEA 记得装插件
