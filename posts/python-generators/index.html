Python 生成器与 yield 详解

生成器（Generator）是 Python 中处理大量数据的神器：它不会一次性把所有数据加载进内存，而是按需逐个产出

📅 2019-03-10⏱ 2 分钟阅读🐍 Python

生成器（Generator）是 Python 中处理大量数据的神器：它不会一次性把所有数据加载进内存，而是按需逐个产出。

什么是迭代器

可以被 for 循环遍历的对象叫可迭代对象，例如列表、元组、字典、字符串。迭代器是实现了 __iter__ 和 __next__ 方法的对象：

nums = [1, 2, 3]
it = iter(nums)
print(next(it))  # 1
print(next(it))  # 2

生成器函数与 yield

函数体里只要有 yield，这个函数就是生成器函数，调用它不会执行函数体，而是返回一个生成器对象：

def count_up_to(n):
    i = 0
    while i < n:
        yield i
        i += 1

g = count_up_to(3)
print(next(g))  # 0
print(next(g))  # 1
print(next(g))  # 2

每次调用 next()，函数从上次 yield 的位置继续执行，直到遇到下一个 yield 或函数结束。

生成器表达式

类似列表推导式，只是把方括号换成圆括号，得到的是生成器而不是列表：

squares = (x * x for x in range(10))
print(sum(squares))  # 285

实战：读取大文件

用生成器逐行读取文件，避免把整个文件载入内存：

def read_lines(path):
    with open(path, encoding='utf-8') as f:
        for line in f:
            yield line.strip()

for line in read_lines('big.log'):
    if 'ERROR' in line:
        print(line)

send 与 yield from

send() 可以向生成器传入值，yield from 可以委托给另一个可迭代对象：

def sub():
    yield 1
    yield 2

def main():
    yield from sub()
    yield 3

print(list(main()))  # [1, 2, 3]

总结

  • 生成器按需计算，节省内存，适合大数据、流式处理场景
  • yield 让函数变成可暂停/恢复的状态机
  • 生成器表达式是轻量的惰性计算方式
