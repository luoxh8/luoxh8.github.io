Vim 常用操作

服务器上没有 IDE，改配置、看日志全靠 Vim

📅 2026-08-07⏱ 1 分钟阅读🛠️ 开发工具

服务器上没有 IDE，改配置、看日志全靠 Vim。掌握基础操作，应急不求人。

三种模式

普通模式 Normal（默认）
插入模式 Insert（按 i 进入）
命令模式 Command（按 : 进入）

常用切换：

i      光标前插入
a      光标后插入
o      下一行插入
Esc    回普通模式

移动与编辑

h j k l    左 下 上 右
w / b      按词移动
0 / $      行首 / 行尾
gg / G     文件头 / 文件尾
x          删除字符
dd         删除整行
yy         复制整行
p          粘贴
u          撤销
Ctrl+r     重做

查找与替换

/keyword    向下查找，n 下一个，N 上一个
?keyword    向上查找

:s/old/new          替换当前行第一个
:s/old/new/g        替换当前行全部
:%s/old/new/g       全文件替换
:%s/old/new/gc      替换前确认

保存退出

:w        保存
:q        退出
:wq       保存并退出
:q!       不保存强制退出
ZZ        保存并退出

服务器应急场景

看日志并搜索：

vim app.log
/ERROR

改 Nginx 配置：

vim /etc/nginx/nginx.conf

没装 vim 时 vi 通用。复杂操作可以 vimtutor 学习。

总结

  • 记住 i Esc :wq 先能活下来
  • dd yy p u 提升编辑效率
  • 查找替换用 %s/old/new/g
