Nginx 常用配置

Nginx 是高性能的 Web 服务器和反向代理，几乎是后端部署的标配

📅 2020-02-12⏱ 2 分钟阅读⚙️ 后端与DevOps

Nginx 是高性能的 Web 服务器和反向代理，几乎是后端部署的标配。

静态资源服务

server {
    listen 80;
    server_name example.com;

    root /var/www/blog;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }
}

反向代理

把请求转发给后端服务：

server {
    listen 80;
    server_name api.example.com;

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

负载均衡

upstream backend {
    server 192.168.1.10:8080 weight=3;
    server 192.168.1.11:8080 weight=1;
    keepalive 32;
}

server {
    listen 80;
    location / {
        proxy_pass http://backend;
    }
}

默认轮询，weight 控制权重，还可以用 ip_hash 做会话保持。

location 匹配规则

写法 优先级 说明
= 精确 最高 location = /login
^~ 前缀 次高 不再查正则
~ 正则 中 区分大小写
~* 正则 中 不区分大小写
/ 通用 最低 兜底 
location = /favicon.ico {
    log_not_found off;
}
location ^~ /static/ {
    alias /data/static/;
    expires 30d;
}
location ~* \.(png|jpg|css|js)$ {
    expires 30d;
}

常见配置

# 限制上传大小
client_max_body_size 50m;

# Gzip 压缩
gzip on;
gzip_types text/plain text/css application/json application/javascript;

# 超时设置
proxy_connect_timeout 5s;
proxy_read_timeout 30s;

# 访问日志格式
log_format main '$remote_addr - $remote_user [$time_local] "$request" '
                '$status $body_bytes_sent "$http_referer"';

常用命令

nginx -t                 # 测试配置
nginx -s reload          # 平滑重载
nginx -s stop            # 停止
systemctl status nginx   # 查看状态

总结

  • 静态资源与反向代理是 Nginx 两大核心场景
  • try_files 适合前端 SPA 路由
  • 改配置先 nginx -t 再 reload
