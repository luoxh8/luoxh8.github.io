Quartz 定时任务

定时任务在业务中很常见：清理数据、生成报表、定时推送

📅 2026-08-07⏱ 2 分钟阅读⚙️ 后端与DevOps

定时任务在业务中很常见：清理数据、生成报表、定时推送。Quartz 是 Java 最成熟的调度框架。

引入依赖

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-quartz</artifactId>
</dependency>

定义任务

public class CleanupJob extends QuartzJobBean {

    @Override
    protected void executeInternal(JobExecutionContext context) {
        // 清理 30 天前的日志
        logService.cleanBefore(LocalDate.now().minusDays(30));
    }
}

注册调度

@Configuration
public class QuartzConfig {

    @Bean
    public JobDetail cleanupJobDetail() {
        return JobBuilder.newJob(CleanupJob.class)
                .withIdentity("cleanupJob")
                .storeDurably()
                .build();
    }

    @Bean
    public Trigger cleanupTrigger() {
        return TriggerBuilder.newTrigger()
                .forJob(cleanupJobDetail())
                .withIdentity("cleanupTrigger")
                .withSchedule(CronScheduleBuilder.cronSchedule("0 0 3 * * ?"))
                .build();
    }
}

每天凌晨 3 点执行。

Cron 表达式速查

格式：秒 分 时 日 月 周

0 0 3 * * ?        每天 3 点
0 */10 * * * ?     每 10 分钟
0 0 9-18 * * MON-FRI  工作日 9-18 点整点
0 0 12 1 * ?       每月 1 号中午
0 0 0/1 * * ?      每小时

注意 Quartz 的 Cron 有 6 位（含秒），且周和日不能同时指定（用 ?）。

传参给任务

JobDataMap data = new JobDataMap();
data.put("days", 30);

JobDetail detail = JobBuilder.newJob(CleanupJob.class)
        .usingJobData(data)
        .build();

任务中读取：

int days = context.getMergedJobDataMap().getInt("days");

动态增删任务

@Service
public class ScheduleService {
    @Autowired
    private Scheduler scheduler;

    public void addJob(JobDetail detail, Trigger trigger) throws SchedulerException {
        scheduler.scheduleJob(detail, trigger);
    }

    public void pause(String jobName) throws SchedulerException {
        scheduler.pauseJob(JobKey.jobKey(jobName));
    }
}

分布式注意

多实例部署时，同一个任务会被多个节点同时执行。解决方式：

  • 用分布式锁（Redis）保证单点执行
  • 任务幂等（重复执行结果一致）
  • 使用 Quartz 集群模式（配置数据库持久化 + 集群）

总结

  • Quartz 支持复杂的 Cron 与动态调度
  • 任务里注入 Service 正常使用
  • 分布式环境记得做幂等或加锁
