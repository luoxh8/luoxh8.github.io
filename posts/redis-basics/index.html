Redis 基础与数据结构

Redis 是内存数据库，读写极快，是缓存、计数、排行榜等场景的首选

📅 2026-08-07⏱ 1 分钟阅读🗄️ 数据库与中间件

Redis 是内存数据库，读写极快，是缓存、计数、排行榜等场景的首选。

启动与连接

docker run -d -p 6379:6379 --name redis redis:7-alpine
redis-cli -h 127.0.0.1 -p 6379

五种核心类型

String 字符串

SET user:1:name "luoxh"
GET user:1:name
SET counter 100
INCR counter          -- 原子自增
EXPIRE user:1:name 3600  -- 设置过期

Hash 哈希

适合存对象：

HSET user:1 name "luoxh" age 26
HGET user:1 name
HGETALL user:1

List 列表

LPUSH queue task1
RPOP queue
LRANGE queue 0 -1

Set 集合

SADD tags:1 python java
SMEMBERS tags:1
SINTER tags:1 tags:2   -- 交集

ZSet 有序集合

排行榜场景：

ZADD rank 100 "user1"
ZADD rank 80 "user2"
ZREVRANGE rank 0 9 WITHSCORES   -- 前十名
ZINCRBY rank 10 "user1"         -- 加分

过期与淘汰

SET code "1234" EX 300   -- 5 分钟过期
TTL code                 -- 查看剩余时间

内存满时的淘汰策略（maxmemory-policy）：

策略 行为
noeviction 直接报错（默认）
allkeys-lru 淘汰最久未使用
volatile-lru 只在带过期时间的键里淘汰
allkeys-random 随机淘汰

生产推荐 allkeys-lru。

持久化

方式 说明 取舍
RDB 定时快照 恢复快，可能丢数据
AOF 追加写日志 更安全，文件大 
appendonly yes
appendfsync everysec

总结

  • 类型选对很重要：对象用 Hash、去重用 Set、排行榜用 ZSet
  • 缓存记得设置过期时间
  • 重要数据开启 AOF
