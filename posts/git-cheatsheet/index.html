Git 常用命令

gitignore 不生效 强制覆盖服务器端代码（master 分支） 强制覆盖本地代码（master 分支）

📅 2018-11-21⏱ 1 分钟阅读🌿 版本控制

快速推送

git add .
git commit -m "quick commit $(date "+%Y-%m-%d %H:%M:%S")"
git push

.gitignore 不生效

git rm -r --cached .
git add .
git commit -m "quick update .gitignore $(date "+%Y-%m-%d %H:%M:%S")"
git push

强制覆盖服务器端代码（master 分支）

git push origin master --force

强制覆盖本地代码（master 分支）

git fetch --all
git reset --hard origin/master
git pull
