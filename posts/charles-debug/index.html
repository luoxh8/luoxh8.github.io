Charles 抓包调试

Charles 是开发联调的神器：看请求、改响应、模拟弱网，前后端问题一抓一个准

📅 2023-01-17⏱ 1 分钟阅读🛠️ 开发工具

Charles 是开发联调的神器：看请求、改响应、模拟弱网，前后端问题一抓一个准。

安装与基础抓包

Charles 默认抓 HTTP。配置代理：

Proxy → Proxy Settings → HTTP Proxy: 8888

浏览器或系统代理指向 127.0.0.1:8888 即可看到请求。

手机抓包

  1. 手机和电脑连同一 Wi-Fi
  2. 手机 Wi-Fi 代理设为电脑 IP:8888
  3. 手机上访问 chls.pro/ssl 下载并安装证书

之后 HTTPS 也能解密查看。

HTTPS 抓包

Proxy → SSL Proxying Settings
勾选 Enable SSL Proxying
Add: Host 填 *，Port 填 443

断点修改请求

Proxy → Breakpoints

或右键请求 → Breakpoints，之后请求会停在断点，可以：

  • 修改请求参数再放行
  • 修改响应内容再返回

这招联调特别好用：后端还没改好，先用断点模拟返回值。

模拟弱网

Proxy → Throttle Settings
勾选 Enable Throttling
选择带宽（如 3G），可自定义上下行速度

Weak Network 一键模拟高延迟/低带宽，测试超时与重试逻辑。

常用技巧

  • Map Local：把线上接口映射到本地文件，无需后端
  • Map Remote：请求转发到另一个环境
  • Repeat：重放请求，测试幂等
  • 搜索过滤：底部输入 URL 关键字
  • 保存会话：File → Save Session，方便复盘

总结

  • HTTPS 记得装证书
  • 断点/Map Local 是联调利器
  • 弱网模拟别忘测
