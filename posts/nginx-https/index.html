Nginx 配置 HTTPS

HTTPS 是线上服务的标配

📅 2021-04-27⏱ 1 分钟阅读⚙️ 后端与DevOps

HTTPS 是线上服务的标配。Let’s Encrypt 提供免费证书，配合 Certbot 自动续期。

申请证书

安装 Certbot 并申请（需要域名已解析到服务器）：

apt install certbot python3-certbot-nginx
certbot --nginx -d example.com -d www.example.com

申请成功后证书位于 /etc/letsencrypt/live/example.com/。

配置 443

server {
    listen 443 ssl;
    server_name example.com;

    ssl_certificate /etc/letsencrypt/live/example.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/example.com/privkey.pem;

    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;
    ssl_session_cache shared:SSL:10m;

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

HTTP 跳转 HTTPS

server {
    listen 80;
    server_name example.com;
    return 301 https://$host$request_uri;
}

自动续期

证书有效期 90 天，用 crontab 自动续期并重载：

crontab -e

# 每天凌晨 3 点检查续期
0 3 * * * certbot renew --quiet --renew-hook "nginx -s reload"

验证配置

nginx -t
curl -I https://example.com

也可以用 openssl 检查证书链：

openssl s_client -connect example.com:443 -servername example.com

常见问题

证书配置后访问报错：检查证书路径、权限，nginx -t 看具体错误。

页面里仍有 http 资源被拦截：把项目中的 http 引用改成相对路径或 https。

反向代理后前端拿不到 https：后端要读取 X-Forwarded-Proto 头：

proxy_set_header X-Forwarded-Proto $scheme;

Spring Boot 中配合：

server:
  forward-headers-strategy: framework

总结

  • Let’s Encrypt + Certbot 免费且省心
  • 80 端口做 301 跳转，443 提供服务
  • 务必配置自动续期
