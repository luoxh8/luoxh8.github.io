Python dataclasses 数据类

dataclasses 用装饰器自动生成 init / repr / eq 等样板代码

📅 2021-03-05⏱ 1 分钟阅读🐍 Python

dataclasses 用装饰器自动生成 __init__ / __repr__ / __eq__ 等样板代码。

基础用法

from dataclasses import dataclass

@dataclass
class Point:
    x: int
    y: int
    label: str = "origin"

p = Point(1, 2)
print(p)                     # Point(x=1, y=2, label='origin')
print(p == Point(1, 2))      # True

常用参数

@dataclass(order=True)        # 生成比较方法，字段需可排序
@dataclass(frozen=True)       # 不可变，类似 namedtuple
@dataclass(eq=False)          # 关闭 __eq__
class User:
    uid: int
    name: str

field 精细控制

from dataclasses import field, asdict, astuple

@dataclass
class Config:
    name: str
    items: list = field(default_factory=list)   # 可变默认值必须用 factory
    meta: dict = field(default_factory=dict, repr=False)  # repr 中隐藏

print(asdict(Config("a")))    # 转 dict

校验与注意

  • 可变默认值（list/dict）必须用 default_factory，否则多实例共享同一对象。
  • frozen=True 后赋值会抛 FrozenInstanceError。
  • 用 __post_init__ 做字段间校验：
@dataclass
class Range:
    lo: int
    hi: int
    def __post_init__(self):
        if self.lo > self.hi:
            raise ValueError("lo > hi")
