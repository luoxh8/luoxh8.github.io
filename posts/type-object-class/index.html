type、object、class 之间的区别

type 函数是 Python 内置的顶层函数之一，不需要导包就可以使用，该函数也是 Python 为何如此魔法的原因

📅 2018-08-25⏱ 1 分钟阅读🐍 Python

type 函数是 Python 内置的顶层函数之一，不需要导包就可以使用，该函数也是 Python 为何如此魔法的原因。

下面代码为例：

a = 1
type(a)  # int
type(int)  # type
b = 'abc'
type(b)  # str
type(str)  # type

由此可得出：type 生成了 int，int 生成 1。因此是由 type 生成了类对象，再由类对象生成了实例：type -> class -> obj。

基类关系

我们可以生成两个类，Student 类和 MyStudent 类，Student 类是 MyStudent 类的父类，我们再分别查看下他们的基类：

class Student:
    pass

class MyStudent(Student):
    pass

MyStudent.__bases__  # (__main__.Student,)
Student.__bases__    # (object,)

由此我们可以发现 object 是最顶层的基类。

type 既是一个类，也是一个对象。既然 type 也是一个类，我们查看下 type 的基类是谁：

type.__base__  # object

我们可以发现 type 的基类是 object。那我们在查看 object 是由谁生成的：

type(object)    # type
object.__bases__  # ()

object 又是由 type 生成的，也就形成了一开始图片的样子：type 是 object 的类，object 是 type 的基类，二者互为因果，共同构成了 Python 对象模型的基石。
